# Nassiba Taib's Quarto Website

* This repository contains my personal Quarto website created for DSCI 521. 

* The website includes computational blog posts using both R and Python.

## Prerequisites

To build this website, you need:

- Quarto
- uv
- R 4.6.1 or later

## Build Instructions

Clone the repository and move into the project directory:

```bash
git clone https://github.com/Nassibataib/Nassibataib.github.io.git
cd Nassibataib.github.io
